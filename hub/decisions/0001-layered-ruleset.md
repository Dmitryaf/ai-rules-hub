# 0001. Слоистый набор правил вместо одного общего AGENTS.md

Статус: принято.

## Контекст

Полный набор правил включает универсальные ограничения, тематические нормы и локальную специфику. Один объединённый файл был бы противоречивым, дорогим для контекста и неприменимым к проектам другого типа.

## Решение

Использовать четыре слоя:

1. обязательный core;
2. тематические правила;
3. комбинируемые профили;
4. локальные правила и исключения проекта.

Точка входа подключённого проекта остаётся локальной и перечисляет выбранные слои.

## Последствия

- Проект читает только релевантные документы.
- Локальное уточнение не требует fork всего baseline.
- Правило должно быть классифицировано перед добавлением.
- Обновление принятой копии пока выполняется вручную.
- Потребность в автоматическом versioning и sync будет оценена после второго реального подключения.
