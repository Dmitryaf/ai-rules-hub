# Профили проектов

Профиль — всегда читаемая надстройка над baseline для повторяющегося типа проекта. Он содержит назначение и уникальные обязательства, но не дублирует тематические правила.

Канонический состав тем каждого профиля определяется только [`../sync/catalog.json`](../sync/catalog.json). Подключённый проект выбирает профили в manifest, сверяет точный effective-набор через status и объясняет человеческое решение в `.ai-rules/RULESET.md`.

| Профиль | Для чего |
| --- | --- |
| [`standard-product.md`](standard-product.md) | пользовательское приложение или сервис |
| [`data-sensitive.md`](data-sensitive.md) | данные с высокой ценой раскрытия или потери |
| [`research-driven.md`](research-driven.md) | решения зависят от исследования или runtime evidence |
| [`learning-project.md`](learning-project.md) | доставка одновременно является обучением владельца |
| [`public-repository.md`](public-repository.md) | репозиторий публичен или готовится к публикации |

Профили можно сочетать. Локальное исключение записывается в `RULESET.md`; оно не меняет композицию каталога и не отменяет ограничения среды или владельца.
