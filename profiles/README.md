# Профили проектов

Профиль — всегда читаемая надстройка над базовым набором для устойчивого свойства проекта. Он содержит назначение и уникальные обязательства, но не дублирует тематические правила. Сочетание профилей не является наследованием или зависимостью между ними.

Профиль сохраняет нормативную силу, но не запускает модернизацию всего репозитория. Его требования применяются сразу к новым и изменяемым файлам; разрыв в нетронутых файлах фиксируется, а не исправляется автоматически. Требование, связанное с внешним действием, становится обязательной проверкой только перед этим действием. Выбор профиля не разрешает аудит всего репозитория, а рекомендованный локальный документ не создаётся без отдельной необходимости и согласованных границ.

Канонический состав тем каждого профиля определяется только [`../sync/catalog.json`](../sync/catalog.json). Подключённый проект выбирает профили в manifest, сверяет точный effective-набор через status и объясняет человеческое решение в `.ai-rules/RULESET.md`.

| Профиль | Для чего |
| --- | --- |
| [`standard-product.md`](standard-product.md) | пользовательское приложение или сервис |
| [`data-sensitive.md`](data-sensitive.md) | данные с высокой ценой раскрытия или потери |
| [`research-driven.md`](research-driven.md) | решения зависят от исследования или данных о выполнении |
| [`learning-project.md`](learning-project.md) | доставка одновременно является обучением владельца |
| [`public-repository.md`](public-repository.md) | репозиторий публичен или готовится к публикации |

Профили можно сочетать. `standard-product` обычно является основой пользовательского приложения; `learning-project`, `public-repository` и `data-sensitive` часто выступают дополнительными профилями. `research-driven` может использоваться самостоятельно для исследовательского прототипа или вместе со `standard-product`.

| Сценарий | Profiles |
| --- | --- |
| Обычное приложение | `standard-product` |
| Учебное приложение | `standard-product + learning-project` |
| Публичное приложение | `standard-product + public-repository` |
| Публичный учебный проект | `standard-product + learning-project + public-repository` |
| Приложение с чувствительными данными | `standard-product + data-sensitive` |
| Исследовательский прототип | `research-driven` |
| Продукт, зависящий от исследования | `standard-product + research-driven` |

Это рекомендации, а не ограничения: одиночный overlay-профиль допустим, если выбор осознан. Topics добавляются отдельно для классов задач, не выраженных выбранными profiles. Локальное исключение записывается в `RULESET.md`; оно не меняет композицию каталога и не отменяет ограничения среды или владельца.
