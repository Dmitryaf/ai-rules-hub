# Профили проектов

Профиль — это готовая надстройка над baseline, а не самостоятельный полный набор. Проект может выбрать несколько профилей и записать выбор в локальном `RULESET.md`.

| Профиль | Для чего |
| --- | --- |
| [`standard-product.md`](standard-product.md) | обычное пользовательское приложение или сервис |
| [`data-sensitive.md`](data-sensitive.md) | личные, финансовые, медицинские или иные чувствительные данные |
| [`research-driven.md`](research-driven.md) | продукт зависит от исследований, runtime evidence или неизвестного API |
| [`learning-project.md`](learning-project.md) | разработка одновременно является обучением владельца |
| [`public-repository.md`](public-repository.md) | репозиторий публикуется или готовится к публикации |

Профиль не копируется вслепую. В `RULESET.md` нужно указать, почему он выбран, какие локальные документы конкретизируют его и какие пункты пока являются release gate, а не текущим фактом.
