# Промпт подключения проекта

Используйте этот запрос в AI-агенте, запущенном из корня подключаемого проекта. CLI хаба находится по пути, указанному в запросе.

## Готовый запрос

```text
Подключи этот проект к AI Rules Hub через {{HUB_CLI_PATH}}.

Работай по этапам:
1. Сначала только прочитай git status, локальные инструкции, основные точки входа, конфигурацию и команды проверки проекта. Сохрани несвязанные изменения владельца.
2. Выбери минимальный подходящий набор profiles и topics. Объясни выбор простыми словами и укажи точные идентификаторы. Не подключай тему только потому, что она существует в каталоге.
3. Если manifest ещё отсутствует, выполни `connect -ProjectRoot "{{PROJECT_ROOT}}"` с выбранными `-Profiles` и `-Topics`. Если проект уже подключён, выполни `connect -ProjectRoot "{{PROJECT_ROOT}}"` без изменения состава.
4. Покажи, какие project-owned файлы созданы initializer, какую revision предлагает хаб и какие managed-файлы Plan добавит или изменит. Объясни, что останется нетронутым.
5. Остановись перед `-Apply` и запроси одно явное разрешение на применение показанного Plan.
6. После разрешения повтори ту же команду с `-Apply`. Проверь автоматические результаты doctor и status, затем покажи diff целевого проекта.

Границы:
- не редактируй `.ai-rules/upstream/` вручную;
- не устраняй найденные разрывы проекта в рамках подключения;
- не выполняй commit, push, публикацию, удаление или изменение истории без отдельного разрешения;
- если выбор правил или Plan содержит существенную неоднозначность, дай одну рекомендацию и задай один конкретный вопрос.

В конце кратко сообщи: выбранный набор, созданные и обновлённые файлы, результат проверки, оставшиеся предупреждения и следующий отдельный шаг.
```
